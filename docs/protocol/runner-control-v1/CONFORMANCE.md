# 实现验收清单

状态：下列是**尚待真实运行时实现后执行**的验收，不是本包已通过的集成测试。结构与内存参考测试记录见 VALIDATION.md。每个结果应记录环境、版本、输入摘要、事件游标和可复核证据；失败项不得标 verified。

| 编号 | 场景 | 必须观察到的行为 |
|---|---|---|
| C01 | 当前 SDK 与 Desktop 基线 | 保留已存在的续接和人工介入路径；Desktop 可见性独立记录。 |
| C02 | 未初始化直接 run.start | SETUP_REQUIRED；无后端调用，无付费副作用。 |
| C03 | 相同请求重复/并发到达 | 只有一个 Operation/Run；返回原结果；同键不同载荷拒绝。 |
| C04 | 幂等记录存在但客户端 revision 已旧 | 检查当前访问权后返回原记录，不新建操作。 |
| C05 | 事务 A 前宕机 | 无执行发生，重提可安全受理。 |
| C06 | A 后、交付标记前宕机 | 同一 outbox 恢复；重新验证授权、预算和租约。 |
| C07 | 外部执行完成而响应丢失 | 查询/对账，无证据时 UNKNOWN_REMOTE；不重复创建 PR、消息或任务。 |
| C08 | 事务 B 提交后响应丢失 | 重放原 Operation/Event；不重结算、不重执行。 |
| C09 | 数据库重启/进程终止 | 任务、意图、幂等键、预算预留、租约和事件保留；参考内存测试不能代替此项。 |
| C10 | 两个 Worker 争抢/旧 Worker 迟到 | 单一编排者；过期 fencing token 拒绝新动作和状态写入。 |
| C11 | 取消后立刻断线重连 | desired_state 保持 CANCELED；只完成对账/停止，不重新推进任务。 |
| C12 | 后端受理 interrupt 但子进程仍运行 | 保持 PAUSING/CANCELING，不显示已安全停止。 |
| C13 | 观察订阅被 AbortSignal 终止 | 不把退出订阅当成远端任务取消。 |
| C14 | 后端失败但已有部分变更 | 保留已发生副作用；新修复/补偿重新授权，不盲重试原动作。 |
| C15 | CAS 旧 State/旧配置写入 | 明确冲突；不得覆盖当前版本或静默采用新配置。 |
| C16 | LLM 声称批准/完成/预算充足 | 没有可信审批、验证器或账本证据则不产生权威状态。 |
| C17 | 授权后更改目标、参数或接收方 | action_sha256 不匹配，拒绝执行并重审。 |
| C18 | 授权过期、撤销或单次次数耗尽 | 派发前拒绝；已交付请求不能假装已撤回。 |
| C19 | 路径穿越、符号链接替换、原生命令绕行 | 执行点实际边界生效；无法拦截的后端只能声明较低保障。 |
| C20 | 编译/测试试图读取密钥或联网 | 隔离和凭据边界限制；worktree 与提示词不充当沙箱。 |
| C21 | 多个角色并发预留同一预算 | 事务中预留，不能超分；未知结果保持占用。 |
| C22 | 无 token/费用数据或实际超额 | 未知不是零；真实超额入账并停止新增受理，不伪造硬上限。 |
| C23 | 订阅额度失效/耗尽 | 不静默切 API、Fast 模式、其他账号或自动充值。 |
| C24 | 事件重复、乱序到达、游标过期 | 去重并按本任务序号恢复；过期明确报错并要求快照重同步。 |
| C25 | 模型/会话丢失后用 Capsule 恢复 | 核实资源哈希、State 版本和未决 Action；无证据时不得重做副作用。 |
| C26 | 原生客户端人工修改 | 接管前停止派发；归还时检查线程、产物和目标变化，失效旧验收。 |
| C27 | 审查后代码发生改变 | 不复用不适用的审查结论；按新版本复验。 |
| C28 | 实施成功但审查后端不可用 | 排队/阻塞或采用已批准替代者，不默认为自审通过。 |
| C29 | sc App 退出或 live ID 改变 | 标记失联/对账；按 native 记录恢复，不能假装 team 持续运行。 |
| C30 | Grok 文档/安装版 flag 不一致 | 固定版本探测；无法确认的能力保持 unknown，不用猜测参数。 |
| C31 | Bot 复制与模板升级 | 不复制作者 Grant/会话/密钥；新增权限和数据去向需重新批准。 |
| C32 | 跨 namespace/账号/环境伪造引用 | 认证后逐项拒绝越权，不能凭 ID 或字符串相同绑定会话。 |
| C33 | 格式异常、重复 JSON 键、巨型输入、未知扩展 | 输入边界先拒绝，不进入外部执行；JCS 以官方测试向量验证。 |
| C34 | 预算、身份与 Policy 更新竞态 | 受理及派发端重核；不能使用失效的预检查结果放行。 |

每个 adapter profile 独立通过安装、登录、创建、续接、结构化事件、中断确认、审批桥、用量、原生引用和外部活动检测的适用测试；不支持的能力明确为 unsupported，未测的为 unknown/documented。首个公开版本至少通过核心持久性、授权与一条真实后端链路，不以支持后端数量作为完成标准。
