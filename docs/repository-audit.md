# 首版源码范围

[中文](repository-audit.md) | [English](en/repository-audit.md)

首版源码包含 Asterun 核心、独立插件、测试、配置样例、协议材料和中英文文档，采用 Apache-2.0。第三方依赖使用各自许可证。

源码快照保留 102 个运行文件的原始字节，内容清单及插件的可复现核验方式见[来源说明](source-provenance.md)。测试使用临时环境、fake 后端或协议替身。

历史部署、迁移记录、原生会话和旧实现参考树保存在维护者的独立归档中。当前快照使用通用路径示例，账户和运行状态由部署环境管理。`.gitignore` 排除凭据文件、环境文件和 SQLite 状态，公开示例继续保留。

发行检查核对 wheel/sdist 成员、文档链接、个人路径和许可文本。源码快照的最终内容扫描、离线测试与包重建结果应在发布前完成并记录，既有验证状态见[发行说明](release-v0.1.md)。
