# Asterun 标准 skill 改造计划

本次从已完成输入优化和 R5 实验的 `9bf30db` 开始，在 `codex/standard-skill` 实施。主工作区仍为 `0ce86a9`，两者不能混作部署版本。改造目标是减少调用方的机械编排和正文搬运，同时保留已有执行、权限、会话与验收语义。R5 没有证明压缩净收益，本次也不预设 Token 节省比例。

首版采用 `integrations/skills/asterun/` 标准目录，包含简短的 `SKILL.md`、可独立运行的 Python 标准库脚本、按需读取的工作流说明和宿主 UI 元数据。脚本通过已安装 CLI 的 `--connect` 连接显式指定的常驻实例，不直接打开数据库、不启动执行核心、不配置账户、不选择或改变模型。GrokBot 现有技能与消息交付保持独立。

第一阶段固定接口：发现实际后端、从工作区文件提交任务、紧凑状态与有界等待、显式读取完整证据、固定文件快照、从既有真实报告生成评价请求、从快照生成有限修复请求、用量和取消。等待使用 `--compact --no-events`；观察到期复用原任务，运行成功与验收通过分别返回。审批和未决结果交给主控核实，脚本不自动批准、重派、压缩或增加修复预算。

第二阶段实现可靠调用：每次操作先保存私有派生调用记录，再执行一次 CLI。完整请求、响应与 stderr 留在私有文件，模型只收到状态、标识和证据路径；本地文件不是另一个任务状态账本。响应损坏、超时或中断时保留未知语义与原请求，不自动重试。评价与修复机械复用快照中的任务、运行、配置 revision、输入和目标哈希，最终仍由核心重新验证。报告必须已经由真实检查产生，脚本不制造通过结果、不运行任意测试命令。

第三阶段做临时目录与 fake 后端验收，覆盖提交重放、有限修复重放、目标漂移拒绝、审查要求保留、成功/失败/审批/未决/观察到期、取消确认区别、损坏响应、客户端超时、输出界限和私有文件。验证独立复制的 skill 能调用安装后的核心，不依赖源码路径或本机凭据。

第四阶段提供固定文件清单的独立 skill 包和 SHA 校验清单，更新使用说明与 STATUS。发行包不包含账户、会话、运行记录或测试夹具。确认本机目标目录没有同名技能后安装通用技能；不切换生产核心或自动停用既有 MCP。核心 wheel/sdist、skill 包和 Antigravity 来源分别检查。

本轮实际效果仅报告 fake 流程中的模型可见返回字节、脚本内观察请求与必需的主控往返边界；主控 Token、真实模型质量、跨客户端触发效果和订阅扣量保持未测。真实对照应固定 base commit、提示、模型/effort、权限、验收与修复上限，再按单独确认的调用预算比较。

## 实施与验证结果

四个实施阶段已完成。实现提交为 `d109ea1`，本机技能安装包的 manifest 固定完整 SHA `d109ea1f8b5ef548b05e685887eed907bc911a20`。后续状态文档提交不会改动已打包的技能成员。新增入口不需要数据库迁移，没有改变核心执行代码、原协议、CLI/MCP schema 或 GrokBot 模板。

隔离全量命令为 `ASTERUN_VERIFY_TMP=/tmp/asterun-standard-skill-0930/offline bash scripts/verify-offline.sh`，退出码 0，2553 项通过、4 个真实后端跳过。收集结果共 2557 项，与进度计数一致。安装后专项在没有源码和 PYTHONPATH 的独立目录中通过 28 项，调用模块实际来自独立 wheel 的 site-packages，技能也由复制目录运行；子进程使用显式 fake 配置。

验证覆盖提交同键同目标复用、同键不同目标拒绝、修复同任务和同操作重放、后继重新绑定、目标漂移拒绝、外部报告来源与独立审查要求保留、成功/失败/审批/未决/到期、取消受理与终止区分、客户端超时和损坏响应只调用一次、旧核心字段拒绝不回退、未知状态不报完成、路径越界/符号链接/FIFO/重复 JSON/非法等待预算、核心状态目录不能用作派生证据目录，以及固定包清单与成员哈希。早期夹具使用了错误的 fake 场景名、过短进程时限和不同接口回执字段假设，另有测试编辑失误；修正后进行了上述清洁全量与独立安装回归，早期失败日志保留在私有证据中。

本机用户技能目录已安装，格式验证与脚本帮助入口通过；这些证明文件就位与脚本可执行，不证明当前聊天已加载、自动触发或跨宿主可用。没有改变已有 Asterun 实例、账户、MCP 配置或原生客户端，也没有调用真实模型、push、合并或切换生产部署。

私有证据保存在本工作树 `.local/standard-skill-20260930`，包含独立 ZIP、SHA256SUMS、安装回读和离线/安装/包装日志及摘要。未保存认证文件或真实原生推理。后续真实收益实验需要固定任务与质量门并单独确认预算；回滚入口可移除本次新增的用户技能目录，已有核心任务与原生会话仍由原实例管理。
