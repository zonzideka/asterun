私有证据位于独立工作树的 .local/token-optimization-r5-20260924：保存三次尝试的脚本、冻结输入、报告、检查日志、验收回执、只含条目类型/终态的原生回读，以及 SQLite 一致备份和 SHA 清单。SQLite integrity_check 均为 ok。没有将凭据、原始推理或完整原生日志复制进证据包；这些私有材料不进 Git 或发行包。原生临时目录中的历史未改写。
