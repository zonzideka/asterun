# R5 小样本真实实验待确认清单

状态：只准备实验，不执行模型。依据 v1.1 复核计划 R5 的“必须另有明确预算授权”。本清单不修改生产配置，不启用按量付费或 On-demand，不升级客户端。R4 当前只完成 Codex 原生路径的离线协议验证，因此先比较普通续接与 native_compact；handoff_fresh 另批验证，不把两种变化混入一个候选。

## 固定实验设计

建议首次仅执行一个成对案例，用来排查真实协议与计量问题，不用于证明统计节省。候选任务为一个隔离 Python 配置解析器：实现由键值行读取重试参数，保留原始输入；第二轮补齐零值、空白与无效数值边界。第一轮要求有效整数正常解析、重复键拒绝；第二轮要求 retries=0 合法、负值拒绝、空值拒绝、空白行跳过、错误包含行号、未知键拒绝。不得新增依赖、网络请求、子 Agent、外部文件访问或改变公共函数签名。工作提示必须同时写清这些限制，验收固定为上述边界和原有正常路径全部通过。

初始模块、九项消费者测试和两轮原始提示已固定在 [r5-fixture](r5-fixture/PROMPTS.md)，逐文件 SHA 见 [MANIFEST.json](r5-fixture/MANIFEST.json)。该起点故意保留缺陷，已确认测试失败；它不属于产品代码。授权后将这份固定输入初始化为独立临时 Git 仓库，A/B 使用相同 base commit 的独立工作树。测试内容在模型执行前冻结，不能按产物修改。两个臂各执行第一轮，再用同一第二轮提示在原 Task 内 workflow.repair。A 保持普通原生续接；B 在两轮之间创建同范围交接包并执行一次 native_compact。除压缩外，投递材料、工具权限、模型、effort、验收、run/repair 上限均一致，不启用 R2 去重以免混变量。

单臂最多 2 个工作轮次、1 次修复；总计最多 4 个工作轮次、1 次压缩，5 个原生阶段。失败即保留该样本，不重做、不新增第三臂。原生模型内部工具循环和请求数不可见，这个上限不是“最多 5 次模型请求”。每个工作轮次观察期限建议 5 分钟，压缩完成观察沿用 60 秒；到期停止后续派发，远端取消仍需确认，不能承诺到期即零消耗。

第一次顺序固定 A→B，记录可能的跨会话缓存影响。若以后另批授权第二对，使用 B→A。不得把一个臂人工预热、另一个臂冷启动而不记录。新线程仍可能共享提供方缓存，warm/cold 以实际可见证据记录，未知保留 unknown。

## 必须确认的模型、profile 与消费边界

真实后端拟用现有 Codex App Server。R4 只读核验的安装版本是 codex-cli 0.155.0-alpha.16；授权后需重新核对二进制、schema 摘要和实际模型路由。模型名称、版本/别名、effort、账户/套餐及原生有效 profile 尚未确认，不能根据当前主控名称推定子进程模型。profile 需固定 cwd、approvalPolicy、sandbox、工具/网络、配置摘要；如果当前入口无法证明两臂一致，停止实验。

建议轮次授权为上面的 5 个原生阶段，额外付费预算为 0：沿用用户明确指定的现有订阅，不切换账户、不启用超额计费。若无法只读确认套餐和路由，或用户需要严格货币/Token 硬上限，则本实验不启动。当前适配器不具备逐模型请求预算守卫，不能把观测阈值写成收费硬上限。用户需要明确接受“以轮次和停止后续派发为约束，内部 Token 总量没有严格硬停”的边界；也可以保持离线。

执行前须补齐并冻结：用户选定的模型与 effort、账户/路由的非秘密标识、profile 摘要、最终候选代码提交、上述固定任务与测试 SHA 的现场复核，以及对 5 阶段预算的授权记录。此处空缺不是默认同意。没有这些记录，只能继续离线工作。

## 采集、停止条件与结论口径

复用 Task/Run、context_transition、usage.report(include_observations)、manifest 和原生事件；记录每个阶段起止时间、线程/轮次引用、输入与源码 SHA、终态、验收、失败/超时、缓存计数与采集完整性。压缩阶段也进入时间与用量观察，不能作为免费操作忽略。主控用量若无法完整获得，明确标成未观测；不保存账户秘密、原始推理或扩大原生日志留存。

原生累计值不按 run 求不可信差值。完整新线程的最终累计值仅能在身份、范围和计量完整时用于该实验臂的 session 观察；缺失、乱序或重置使相应比较失效。旧会话导入、轮询和实时观察不得重复累加。分别报告 payload 字节、native_usage、端到端质量与 subscription_quota_effect，后者没有账单证据时始终 unknown。

出现身份/profile 漂移、审批未决、异常工具权限、来源文件变化、用量缺失、压缩 ACK 后无确定完成、断连、预算边界或验收失败时，停止后续派发，保留失败样本和原幂等键。恢复只对账，不换键重跑。不得为“凑齐样本”自动提高次数。

这个单对 pilot 不满足既有 compare-workflow-samples.py 的 6—10 类三路径样本门槛，不使用它输出完整比较结论，也不降低工具门槛。真实结果应单独写入实验记录；只有进一步授权并取得成对代表性样本后，才讨论净收益、Astra 模式搭配或默认策略。
